# 集計ページのグラフを縦棒のヒストグラムにする

## 背景

`/stats` のグラフは、区間ごとに横棒を1行ずつ並べている(`docs/spec-result-stats.md` の7章)。分布の形が見えにくいので、横軸に値・縦軸に人数をとる縦棒のヒストグラムにする。オーナーの要望:「グラフも分布みたいにヒストグラムみたいにして欲しい」。

区間の決め方(`src/stats/summary.ts` の `histogram`)・自分の区間の決め方(`binIndexOf`)・集計の中身は変えない。見た目だけを変える。

## 変更対象

- `src/stats-page/chart.ts`(新規): 目盛りを選ぶ純粋な関数 `axisTicks`
- `src/stats-page/main.ts`: `Chart` 型と `chartHtml` と、各グラフの呼び出し
- `src/stats-page/stats.css`: `.stats-row` / `.stats-bin` / `.stats-track` / `.stats-people` を消して、縦棒のスタイルに置き換える
- `tests/stats-chart.test.ts`(新規)

触らないもの: `src/stats/**`、`worker/**`、`src/style.css`、`wrangler.jsonc`、ゲーム側の画面。

## 仕様

### 1. 形

```
正解数(文字)
              あなた
          12   9
       5  ██   ██   3
   1  ██  ██   ██  ██   ← 棒の上に人数
  ███████████████████   ← 底の線
  0       20       40   ← 区間の境目の目盛り
```

- 区間ごとに縦棒を1本ずつ、左から値の小さい順に横に並べる。棒は同じ幅で、グラフの横幅いっぱいに均等に割る(flex で `flex: 1`)。棒と棒の間は 2px。
- 棒を描く領域の高さは 120px。棒の高さは `count / maxCount * 100%`(`maxCount` は今と同じく `Math.max(1, ...counts)`)。人数が 0 の区間は高さ 0 で、場所だけ空ける。
- 棒の色は今と同じ: 通常は `--primary`、自分の区間は `--primary-strong`。棒の下に 1px の底の線(`--line`)を引く。
- 各棒に `title` 属性で `<区間の文字列> <人数>人` を付ける(PC で見たときの補助。区間の文字列は今の `label` 関数の出力をそのまま使う)。

### 2. 人数の表示

- 区間の数が **12 以下** のとき、人数が 1 以上の棒の真上に人数(数字だけ、`人` は付けない)を 10px で出す。
- 区間の数が 13 以上のときは棒の上に人数を出さない(幅が狭くて重なるため)。代わりにグラフの見出しの右に `最大 N人`(N は `maxCount`)を小さく出す。

### 3. 自分の位置

- 自分の区間がある(`mine` が null でない)とき、その棒の上に `あなた` を `--primary-strong`・10px・太字で出す。人数の表示があるときは人数の上に重ねて出す。
- 自分の区間が人数 0 になることはない想定だが、0 でも `あなた` は出す。

### 4. 横軸の目盛り

区間の境目の値を、棒の下に最大 6 個まで出す。どの境目を出すかは `src/stats-page/chart.ts` の純粋な関数で決める。

```ts
/** 区間の数 binCount から、目盛りを出す境目の番号(0〜binCount)を小さい順に返す */
export function axisTicks(binCount: number): number[];
```

- 境目は `0`(最初の区間の左端)から `binCount`(最後の区間の右端)までの `binCount + 1` 個ある。境目 `i` の値は、`i < binCount` なら `bins[i].from`、`i === binCount` なら `bins[binCount - 1].to`。
- `step = Math.ceil(binCount / 5)` として、`0, step, 2*step, …` のうち `binCount` 以下のものを返す。最後が `binCount` でなければ `binCount` を足す。ただし、足す直前の最後の値と `binCount` の差が `step / 2` 未満なら、その最後の値を `binCount` に置き換える(目盛りの文字が重ならないように)。
- `binCount` が 0 のときは空の配列。

| binCount | 返り値 |
|---|---|
| 0 | `[]` |
| 1 | `[0, 1]` |
| 5 | `[0, 1, 2, 3, 4, 5]` |
| 10 | `[0, 2, 4, 6, 8, 10]` |
| 20 | `[0, 4, 8, 12, 16, 20]` |
| 7 | `[0, 2, 4, 6, 7]`(6 と 7 の差 1 は `step / 2` = 1 未満ではないので置き換えない) |
| 13 | `[0, 3, 6, 9, 13]`(12 と 13 の差 1 < 1.5 なので 12 を 13 に置き換え) |

- 目盛りは、境目の位置(左端から `i / binCount * 100%`)を中心に置く。左端の目盛りは左揃え、右端の目盛りは右揃えにして、グラフの外にはみ出さないようにする。
- 目盛りの文字は 10px・`--subtle`。値の書き方はグラフごとに次の関数で決める(`Chart` 型の `label` の隣に `tick: (value: number) => string` を足す)。

| グラフ | 見出し | 目盛りの書き方 |
|---|---|---|
| タイムアタックの正解数 | `正解数(文字)` | `String(value)` |
| タイムアタックの正確率 | `正確率` | `${Math.round(value * 100)}%` |
| タイムアタックの打鍵速度 | `打鍵速度(文字/秒)` | `String(value)` |
| 耐久の進んだ割合 | `進んだ割合` | `${Math.round(value * 100)}%` |

### 5. 変えないこと

- 「まだ記録がありません」の出し方、上位○%、人数・プレイ数の行、モードの切り替え、読み込み中・エラーの表示。
- `<input>` などの入力要素は使わない。棒はタップしても何も起きない。

### 6. テスト

`tests/stats-chart.test.ts` に、4章の表の1行ごとに `it` を1つ書く。DOM の描画はテストしない。

## 受け入れ条件

- `npx tsc --noEmit` / `npm run typecheck:worker` / `npm test` / `npm run build` / `npm run format:check` がすべて通る
- `tests/stats-chart.test.ts` に4章の表の行と同じ数の `it` がある
- `git diff --stat` が「変更対象」のファイルだけを含む
- `grep -n "stats-row\|stats-track\|stats-people" src/stats-page` が空

## 対象外

- 棒をタップして詳細を出すこと
- 区間の幅や区間の数を変えること
- 縦軸の目盛り線

## 想定される落とし穴

- 正確率と進んだ割合の境目は `0.1 * 3` のような小数の誤差を含む。目盛りは必ず `Math.round(value * 100)` を通して出す。
- 区間が多いとき(正解数で 30 区間など)、棒は 1 本 10px 前後まで細くなる。棒の最小幅は付けず、横スクロールも出さない(ページの横スクロールを出さない)。
- `あなた` と人数を棒の上に積むと、いちばん高い棒では 120px の領域からはみ出す。棒の領域の上に 28px の余白をとって、そこに収める。
